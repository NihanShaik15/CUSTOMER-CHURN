📉 Customer Churn Prediction — Telco Dataset¶

Goal: Predict which customers are likely to stop using the service (churn), so the business can proactively retain them.

Dataset: IBM Telco Customer Churn — 7,043 customers, 21 features (demographics, account info, services subscribed).

Approach:

  1. Exploratory Data Analysis (EDA) — understand churn patterns
  2. Data preprocessing — encoding, scaling, train/test split
  3. Model training — Logistic Regression, Random Forest, XGBoost
  4. Evaluation — Accuracy, Precision, Recall, F1, ROC-AUC
  5. Explainability — feature importance & SHAP values

4. Model Training¶

We train 3 classification models and compare them:

  • Logistic Regression — simple, interpretable baseline
  • Random Forest — handles non-linearity, robust to outliers
  • XGBoost — gradient boosting, usually strongest performer on tabular data

All models use class_weight/scale_pos_weight to handle the churn class imbalance (~26% churn vs 74% retained).

In [10]:
results = {}
roc_data = {}

def evaluate(name, model, X_te, y_te):
    y_pred = model.predict(X_te)
    y_prob = model.predict_proba(X_te)[:, 1]
    metrics = {
        "accuracy": accuracy_score(y_te, y_pred),
        "precision": precision_score(y_te, y_pred),
        "recall": recall_score(y_te, y_pred),
        "f1_score": f1_score(y_te, y_pred),
        "roc_auc": roc_auc_score(y_te, y_prob),
    }
    results[name] = metrics
    roc_data[name] = y_prob

    cm = confusion_matrix(y_te, y_pred)
    plt.figure(figsize=(4,3.5))
    sns.heatmap(cm, annot=True, fmt="d", cmap="Blues",
                xticklabels=["No Churn","Churn"], yticklabels=["No Churn","Churn"])
    plt.title(f"Confusion Matrix - {name}")
    plt.ylabel("Actual"); plt.xlabel("Predicted")
    plt.show()

    print(classification_report(y_te, y_pred, target_names=["No Churn","Churn"]))
    return metrics

7. Business Recommendations¶

Based on the analysis:

  1. Target month-to-month customers with incentives to move to annual contracts (biggest churn driver).
  2. Focus retention efforts in the first 3–6 months of a customer's lifecycle — churn risk is highest early on.
  3. Review fiber optic service pricing/quality — these customers churn more than DSL users.
  4. Use the trained model to score customers monthly and flag the top-risk segment for proactive outreach.
